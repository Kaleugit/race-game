# Housekeeping Checklist

Use this checklist for safe repository cleanup.

## Scope
- No product behavior changes.
- No schema/contract changes.
- No hidden refactors.

## Checks
- Task board and session log still readable and consistent.
- Task files in `memory-system/tasks/` follow conventions and are reconciled in the index.
- Workstream notes/history exist for active mapped skills.
- Placeholder cleanup does not remove required templates.
- Markdown links remain valid.
- Governance scripts still pass.
